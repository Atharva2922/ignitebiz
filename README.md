# IgniteBiz AI &ndash; Digital Venture Studio Platform

A complete, high-fidelity, and responsive web application replica and transformation of **[https://ignitebizai.com/](https://ignitebizai.com/)** into an enterprise **Digital Venture Studio** platform.

Crawled, analyzed, and structured using the **`crawl4ai`** asynchronous engine, featuring genuine extracted assets, full multi-page navigation, responsive design systems, interactive components, and comprehensive content.

## 🌟 Overview & Key Concepts

**IgniteBiz AI** is a connected Digital Venture Studio platform transforming human potential through evidence-based psychometric science, early-stage venture building, institutional incubation, and global scaling. Rooted in Indian wisdom (*‘सर्वे भवन्तु सुखिनः।’*) and aligned with the **National Education Policy (NEP 2020)** and **Society 5.0**.

### Core Architecture:
1. **The 12-Stage Operational Startup Journey**:
   - Stage-gated operating system: `01 Reach` &rarr; `02 Assess` &rarr; `03 Ideate` &rarr; `04 Validate` &rarr; `05 Pitch` &rarr; `06 Formalize` &rarr; `07 Protect` &rarr; `08 Launch` &rarr; `09 Fund` &rarr; `10 Operate` &rarr; `11 Globalize` &rarr; `12 Exit-Ready`.
2. **12-Dimension Psychometric Evaluation Test (₹990 / $15)**:
   - Comprehensive assessment across Emotional Intelligence, Problem Solving, Agility, Risk Tolerance, Business Acumen, and Execution.
   - Includes ₹70,000 ($840) in bonus gifts (SEQUA idea validation, Indo-Arab membership, 8 high-impact books, training manuals).
3. **Eye 2 I &ndash; Iris Analysis Test (₹5,555 / $59)**:
   - Innovated by Dr. Sanjay Gautam and affiliated with the **American Research Institute of Dermis & Genetic Evaluation, USA**.
   - Assesses 100 Billion Neurons via the Optical Nerve in &lt;1 minute with 90&ndash;100% accuracy.
4. **Dual Track Architecture**:
   - **Entrepreneurship Track**: Incubation, 5-Year Fractional C-Suite services (CEO, CFO, COO, CMO, CTO, CHRO), and qualification for the **Global Business Innovation Awards ($100k 1st prize)**.
   - **Skill Development Track**: Industry 5.0 certified training programs across AI/ML, Cybersecurity, Cloud, Full-Stack, and UX/UI with direct corporate placement linkages.

## 🚀 Running Locally

To run the website locally on any machine with Python installed:

```bash
# Clone the repository
git clone https://github.com/Atharva2922/ignitebiz.git
cd ignitebiz

# Start local server (port 8000 or 8080)
python -m http.server 8000
```

Open your browser and navigate to:
**`http://localhost:8000/`** (or `http://localhost:8080/`)
