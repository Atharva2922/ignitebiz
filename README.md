# IgniteBiz AI &ndash; Modern Website Replica

A complete, high-fidelity, and responsive web application replica of **[https://ignitebizai.com/](https://ignitebizai.com/)** (*"Igniting Business Yoga with AI"*).

Crawled, analyzed, and structured using the **`crawl4ai`** asynchronous engine, featuring genuine extracted assets, full multi-page navigation, responsive design systems, interactive components, and comprehensive content.

---

## 🌟 Overview & Key Concepts

**IgniteBiz AI** is a global strategic initiative aimed at transforming human potential through evidence-based psychometric science, startup venture studio incubation, and future-tech skill building. Rooted in Indian wisdom (*‘सर्वे भवन्तु सुखिनः।’*) and aligned with the **National Education Policy (NEP 2020)** and **Society 5.0**.

### Core Architecture:
1. **12-Dimension Psychometric Evaluation Test (₹990 / $15)**:
   - Comprehensive assessment across Emotional Intelligence, Problem Solving, Agility, Risk Tolerance, Business Acumen, and Execution.
   - Includes ₹70,000 ($840) in bonus gifts (SEQUA idea validation, Indo-Arab membership, 8 high-impact books, training manuals).
2. **Eye 2 I &ndash; Iris Analysis Test (₹5,555 / $59)**:
   - Innovated by Dr. Sanjay Gautam and affiliated with the **American Research Institute of Dermis & Genetic Evaluation, USA**.
   - Assesses 100 Billion Neurons via the Optical Nerve in &lt;1 minute with 90&ndash;100% accuracy.
3. **Dual Track Architecture**:
   - **Entrepreneurship Track (&ge;60% Score)**: Incubation, 5-Year Fractional C-Suite services (CEO, CFO, COO, CMO, CTO, CHRO), and qualification for the **Global Business Innovation Awards ($100k 1st prize)**.
   - **Skill Development Track (&lt;60% Score)**: Industry 5.0 certified training programs across AI/ML, Cybersecurity, Cloud, Full-Stack, and UX/UI with direct corporate placement linkages.

## 🚀 Running Locally

To run the website locally on any machine with Python installed:

```bash
# Clone the repository
git clone https://github.com/Atharva2922/ignitebiz.git
cd ignitebiz

# Start local server
python -m http.server 8080
```

Open your browser and navigate to:
**`http://localhost:8080/`**

## 🛠️ Built With

- **HTML5**: Semantic, accessible markup with OpenGraph metadata and structured hierarchy.
- **Vanilla CSS3**: Modern variables, glassmorphism, responsive CSS Grid, and custom typography (`Outfit`, `Inter`, `Source Serif 4`).
- **JavaScript (ES6+)**: Zero external JS dependencies. Handles mobile navigation drawer, interactive FAQ accordions, booking modal popups, dynamic number counters, and form validation.
- **Crawl4AI**: High-performance scraping and extraction toolkit.
